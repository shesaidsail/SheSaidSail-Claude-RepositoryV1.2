# Testimonials Needed

Status: the live Elementor testimonial section currently uses placeholder copy (lorem ipsum, a stock avatar, and generic names such as "Customer"). This is the single highest priority trust fix before paid traffic.

Rule: do not publish invented names or invented quotes as real. Every slot below stays in placeholder form until a real client quote and permission are collected.

## How to use this file

1. Collect real quotes using a short post charter message (see template at the bottom).
2. Get written permission to use first name, occasion, city, and vessel.
3. Replace each slot below with the real detail.
4. Once a slot is filled with a real, permissioned quote, move it into the Elementor testimonial widget.

## Recommended final format

```
"Everything felt effortless. We showed up and the whole day was already handled."

Sarah
Bachelorette Weekend
Miami
Vessel: [Vessel Name]
```

## Post charter quote request (paste into DM or email)

Keep it short and human, in brand voice:

> Hey, so glad the day came together the way it did. If you are open to it, would you mind sending one or two lines on how it felt? Happy to use just your first name. It helps other groups know what to expect.

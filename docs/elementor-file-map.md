## How purpose will be determined

Once the JSON is in the repository, each file will be parsed and classified by its widget content:

- Testimonial widgets, repeater testimonials
- Yacht or vessel cards, image placeholders, pricing tables
- CTA buttons
- FAQ accordions or toggles
- Booking or request forms
- Team or founder sections
- Trust or value sections

The suggested new name and import location will then be filled in, and updated import ready copies written to elementor-updated/.

# Paid Traffic Readiness Checklist

Do not send paid traffic until the critical trust items are complete. The first three are existential, the rest are high value.

## Critical trust items

- [ ] No visible lorem ipsum anywhere
- [ ] No fake testimonials shown to traffic
- [ ] No visible ADD BOAT PHOTO placeholders
- [ ] Real yacht photos uploaded for all 11 vessels
- [ ] Real testimonials uploaded (three to five minimum, named and permissioned)
- [ ] Founder or team photo added

## Experience and reassurance

- [ ] Weather and rebooking reassurance visible near pricing
- [ ] FAQ visible on homepage, pricing, and request to book
- [ ] Main CTA visible above the fold
- [ ] Package differentiation line under each experience name
- [ ] How It Works section live
- [ ] Why She Said Sail section live
- [ ] Yacht pages have photos and best use copy
- [ ] Pricing page has clarity and reassurance
- [ ] CTA language upgraded from Inquire to confident luxury CTAs

## Tools and tracking

- [ ] Tidio concierge tested
- [ ] Booking form tested
- [ ] Stripe and deposit flow tested
- [ ] GA4 installed
- [ ] Meta Pixel installed
- [ ] Google Search Console connected
- [ ] UTM capture working
- [ ] Mobile booking flow tested
- [ ] Emma or concierge response tested

## Sign off

- [ ] Spot checked on desktop
- [ ] Spot checked on mobile
- [ ] Final read for any remaining placeholder text
- [ ] Final read for any em dashes in published copy

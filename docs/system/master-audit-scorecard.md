# SHE SAID SAIL — MASTER AUDIT SCORECARD
Version: 1.0 | Status: PRODUCTION | Owner: Will Hunt

---

## AUDIT DIMENSIONS

Each page is scored across 12 dimensions. Scores are honest. A 10/10 means nothing material remains to improve conversion, trust, luxury feel, mobile UX, backend readiness, analytics readiness, clarity, or operational maturity.

---

## SCORING RUBRIC

### 1. Luxury Positioning (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Page feels genuinely premium. Visual, copy, and structure all support the positioning without trying too hard. |
| 7–8 | Strong positioning but one or two elements undercut it. |
| 5–6 | Some luxury signals but generic sections drag it down. |
| 3–4 | Positioned closer to commodity charter than premium hospitality. |
| 1–2 | No luxury positioning evident. |

### 2. Emotional Conversion (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Reader feels desire. The experience is visceral. The CTA feels natural. |
| 7–8 | Strong sections but pacing drops off mid-page. |
| 5–6 | Informational but not emotionally engaging. |
| 3–4 | Reads like a brochure. No desire created. |
| 1–2 | Clinical or off-brand. |

### 3. Mobile UX (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Flawless on 375px. Every element serves the mobile user. |
| 7–8 | Minor spacing or sizing issues but generally functional. |
| 5–6 | Functional but not optimized. Spacing cramped or elements awkward. |
| 3–4 | Several broken experiences on mobile. |
| 1–2 | Not designed for mobile. |

### 4. Trust (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Social proof, reassurance language, operational certainty all present and specific. |
| 7–8 | Trust signals present but not fully leveraged. |
| 5–6 | Generic trust signals only. |
| 3–4 | No meaningful trust evidence. |
| 1–2 | Page creates anxiety rather than trust. |

### 5. CTA Clarity (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Clear hierarchy. Primary, secondary, and form CTAs all obvious and appropriately placed. |
| 7–8 | CTA present but hierarchy could be stronger. |
| 5–6 | CTA exists but weak copy or poor placement. |
| 3–4 | Confusing CTA placement or multiple competing actions. |
| 1–2 | No clear CTA. |

### 6. Copy Quality (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Voice is consistent, warm, specific, and free of prohibited words/patterns. |
| 7–8 | Strong voice in key sections but inconsistent throughout. |
| 5–6 | Adequate copy but generic or template-feeling. |
| 3–4 | Off-brand copy. Prohibited words or patterns present. |
| 1–2 | Significantly off-brand. Salesy or robotic. |

### 7. Visual Consistency (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Palette, typography, and spacing match master system exactly. |
| 7–8 | Minor inconsistencies. Recognizably on-brand. |
| 5–6 | Mostly on-brand but some elements feel generic. |
| 3–4 | Clear visual inconsistencies that undercut positioning. |
| 1–2 | Off-brand visuals. |

### 8. Backend Readiness (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | All form fields mapped correctly, hidden fields present, experience field pre-populated, webhook tested. |
| 7–8 | Form works but hidden fields or UTM capture missing. |
| 5–6 | Form submits but routing, field mapping, or idempotency not verified. |
| 3–4 | Form not connected or fields missing. |
| 1–2 | No form or backend connection. |

### 9. Analytics Readiness (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | GTM loaded, all key events tagged, UTM capture confirmed, GA4 receiving data. |
| 7–8 | GTM loaded, some events missing. |
| 5–6 | Pageview tracked but no event tracking. |
| 3–4 | Analytics present but not configured. |
| 1–2 | No analytics tracking. |

### 10. SEO (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | Title, meta, H1, OG, Twitter, alt text, canonical all correct and optimized. |
| 7–8 | Core SEO present but OG/Twitter or alt text incomplete. |
| 5–6 | Title and meta present but not optimized. |
| 3–4 | Basic SEO only. Missing key elements. |
| 1–2 | No SEO optimization. |

### 11. Performance (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | PageSpeed mobile 85+, LCP under 2.5s, CLS under 0.1. |
| 7–8 | PageSpeed mobile 70–84. One metric needs attention. |
| 5–6 | PageSpeed mobile 55–69. Performance issues present. |
| 3–4 | PageSpeed mobile below 55. Significant issues. |
| 1–2 | Critical performance failures. |

### 12. Operational Maturity (0–10)
| Score | Description |
|-------|-------------|
| 9–10 | QA checklist complete, deployment docs present, page documented in system. |
| 7–8 | Mostly documented. Minor gaps. |
| 5–6 | Page works but no documentation. |
| 3–4 | Ad hoc page with no ops documentation. |
| 1–2 | No operational maturity. |

---

## OVERALL SCORE

Overall = average of all 12 dimensions.

A 9/10 overall means the page is ready for production with minor notes.
A 10/10 requires every dimension to be 9+.

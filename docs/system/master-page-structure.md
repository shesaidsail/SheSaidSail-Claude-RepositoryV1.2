## EXPERIENCE PAGE STRUCTURE

Every experience/package page follows this section order:

### 1. Navigation Bar
- Sticky, transparent over hero, solid on scroll
- Logo left, nav links right
- CTA button in nav: "Reserve Your Date" (gold)

### 2. Hero Section
- Full-viewport height (100vh) or 80vh minimum
- Background: hero image with navy overlay gradient
- Content: eyebrow label + headline + subheadline + CTA button
- CTA anchors to inquiry form section
- No auto-play video

### 3. Experience Overview Strip
- 3–4 key attributes (duration, guests, location, occasion type)
- Horizontal on desktop, 2-col grid on mobile
- Gold icon or number + label + description
- Thin gold rule separator above

### 4. The Experience Section
- Left: editorial copy block (2–3 paragraphs)
- Right: secondary image or photo stack
- Emotional, scene-based language
- No bullet points in this section

### 5. What's Included Section
- Gold section label
- Clean list or card grid (3–6 items)
- Each item: icon/checkmark + concise description
- Calm, specific, no hype language

### 6. Package Details / Pricing
- Price displayed prominently
- "Starting from" if variable
- Duration, guest count range
- Optional: seasonal notes

### 7. Add-Ons Section (optional)
- Card grid 2–3 columns
- Each add-on: name + brief description + price if shown
- Subtle gold accent

### 8. Social Proof / Reviews
- 2–3 testimonials minimum
- Name + occasion type (e.g., "Bachelorette, Miami")
- No photos required but supported
- Stars displayed if using rating

### 9. Inquiry Form
- Clear section heading: "Reserve Your Date" or "Plan Your Experience"
- Gold section label above
- Form fields (see master-backend-system.md)
- Primary CTA: gold button, sentence case
- Below form: reassurance line ("We typically respond within a few hours on weekdays.")

### 10. Other Experiences (optional)
- 2–3 other experience cards
- Cross-sell without pressure

### 11. Footer
- Logo, nav, legal links, social icons

- Address: 1314 East Las Olas Blvd #2597, Fort Lauderdale, FL 33301

## SECTION ORDERING PRINCIPLE

Emotional pacing governs order:
1. Mood before information
2. Desire before logistics
3. Proof before price (where possible)
4. Ask after trust is established

---

## MOBILE PAGE STRUCTURE ADJUSTMENTS

- Hero: 70–80vh, single-column, headline centered
- Overview strip: 2x2 grid
- Experience section: image above copy
- Includes: single column list
- Reviews: single column stacked
- Form: full-width, all fields stacked
- Footer: centered, stacked columns

---

## CTA HIERARCHY

Every page has exactly three CTA levels:

| Level | Purpose | Placement |
|-------|---------|-----------|
| Primary | Anchor to form | Hero section |
| Secondary | Anchor to form | Mid-page (after includes or reviews) |
| Form CTA | Submit inquiry | Within form |

No page should have more than one form. Multiple CTAs point to the same form anchor.

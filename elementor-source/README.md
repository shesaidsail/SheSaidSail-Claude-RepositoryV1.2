# elementor-source

GitHub backed source of truth for all Elementor JSON exports.

Status: awaiting the export files. The Elementor exports currently live in Claude Project knowledge ("SheSaidSail Consierge OS" Files panel), which is not accessible from the Claude Code environment. They could not be copied automatically.

## How to populate this folder

Pick whichever is easiest. Any one of these makes the files readable so the conversion edits can be applied directly.

1. Upload into the chat: drag the elementor-*.json files into the conversation. They become readable immediately.
2. Commit to the repo yourself: place the files in this folder, then commit and push on the current branch.
3. Drop into Google Drive: add the files to the connected Drive folder.

## Naming

Keep the original export files here unchanged. When their purpose is known, a clean descriptive copy can also be added, for example home.json, yachts.json, yacht-detail.json, request-booking.json, header.json, footer.json. Originals are never overwritten.

See docs/elementor-file-map.md for the mapping table.
